# Models & Metadata Artifacts Directory (`models/`)

Contains serialized machine learning models and evaluation summaries generated by `python src/run_pipeline.py`:
- `credit_risk_pipeline.joblib`: Complete inference bundle (`CreditRiskFeatureEngineer`, `selected_features`, `champion_model`, optimal decision thresholds).
- `best_model.joblib`: Serialized Champion Tuned Gradient Boosting classifier.
- `all_models_summary.json`: Complete metrics table across all 8 models, CV tuning results, VIF tables, and global SHAP importances.
- `threshold_analysis.json`: Threshold sweep metrics (`0.05`–`0.90`) and optimal operating regimes (`0.50`, `0.39` F1-optimal, `0.16` 5:1 Cost-optimal).
- `woe_iv_summary.json`: Training-set Information Value ranking and bin-level Weight of Evidence tables.
- `statistical_summary.json`: Parametric and non-parametric statistical test outputs and EDA summary tables.
- `imputation_comparison.json`: Cleaning audit, imputation benchmark (`Global Median` vs `Grade Median` vs `KNN`), and `1,005` ratio mismatch decomposition.
