# Figures Directory (`reports/figures/`)

Contains 16 reproducible PNG visualisations generated by `src/visualization/eda_plots.py` and `src/evaluation/evaluate_model.py`:
- `fig01_loan_status.png` — Target class distribution (`21.9%` default rate).
- `fig02_default_rate_by_grade.png` — Default rate across loan grades `A`–`G`.
- `fig03_default_rate_by_loan_burden.png` — Default rate by `loan_percent_income` bands.
- `fig04_prior_default_and_home_ownership.png` — Default rate by prior bureau default and housing tenure.
- `fig05_default_rate_by_loan_intent.png` — Default rate by stated loan purpose.
- `fig06_income.png` — Log10 income boxplot and income quartile default rates.
- `fig07_loan_amount_and_interest_rate.png` — Default rate by loan amount and interest rate bands.
- `fig08_age_and_employment.png` — Default rate by applicant age and employment tenure bands.
- `fig09_correlation_heatmap.png` — Spearman rank correlation matrix across numerical columns.
- `fig10_woe_iv_summary.png` — Information Value (IV) ranking bar chart with Siddiqi thresholds.
- `fig11_woe_curves.png` — Weight of Evidence (WoE) and default rate curves for top 4 predictors.
- `fig12_roc_pr_curves.png` — ROC and Precision-Recall curves across all 8 models on the test set.
- `fig13_confusion_matrices.png` — Held-out test confusion matrices for top 4 models.
- `fig14_threshold_optimization.png` — Precision/Recall/F1 and 5:1 expected cost curves vs threshold.
- `fig15_shap_summary.png` — Global SHAP feature importance bar plot.
- `fig16_calibration_curve.png` — Reliability / probability calibration curves and Brier scores.
