# Credit Risk Scoring & Loan Default Analysis — ML Backend (Member 4)

FastAPI service that validates loan CSVs, trains and compares Logistic Regression, Random Forest and Decision Tree classifiers, reports real held-out metrics, predicts default risk and explains predictions with SHAP.

> **Architecture guide:** `docs/Credit_Risk_ML_Backend_Architecture.pdf` (diagrams + step-by-step walkthrough). Rebuild it after retraining with `.\.venv\Scripts\python.exe -m pip install -r docs\requirements-docs.txt` then `.\.venv\Scripts\python.exe docs\build_architecture_pdf.py`.

> **Data notice.** No real dataset was supplied, so `data/synthetic_loans.csv` is **synthetic development data** generated by `scripts/generate_synthetic_data.py`. Metrics from it say nothing about real-world credit performance. Upload the team's real dataset through `POST /api/data/upload` and retrain.

## Setup and commands (Windows PowerShell, from `backend/`)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# (optional) regenerate synthetic dev data

.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

# end-to-end smoke run (upload -> train -> predict -> explain, in-process)
```

Environment variables (optional): `CREDIT_RISK_MODEL_DIR`, `CREDIT_RISK_DATA_DIR`, `CREDIT_RISK_MAX_UPLOAD_MB` (default 20), `CREDIT_RISK_CORS_ORIGINS` (default `http://localhost:3000,http://localhost:5173`).

## ML workflow

1. **Validation & quality report** — required target column, label mapping, missing values, duplicates, numbers stored as text, class imbalance, ID/constant columns.
2. **Leakage prevention** — columns whose names indicate post-outcome data (`recover`, `total_pymnt`, `last_pymnt`, `settlement`, `out_prncp`, …) are excluded automatically and listed in `excluded_columns`. Numeric features that alone separate the classes with AUC ≥ 0.98 are flagged as warnings. Add anything else via `exclude_columns`.
3. **Split** — stratified, reproducible (`random_state`) 60/20/20 train/validation/test after deduplication.
4. **Preprocessing** (fitted on train only, saved inside the pipeline): numeric → median imputation + missing indicators + scaling; categorical → constant `__missing__` imputation + one-hot (`handle_unknown="infrequent_if_exist"`, so unseen categories are safe).
5. **Imbalance** — `class_weight="balanced"` (RF: `balanced_subsample`).
6. **Selection & threshold** — validation set picks the model (`selection_metric`, default ROC-AUC) and the decision threshold (max F1, or best precision at `min_default_recall`).
7. **Evaluation** — test-set precision, recall, F1, ROC-AUC, PR-AUC, Brier, confusion matrix, classification report; also test metrics at threshold 0.5 and train metrics for overfitting checks.
8. **Persistence** — `models/credit_risk_model.joblib` (pipeline + schema + metadata) and `models/metrics.json`.
9. **SHAP** — TreeExplainer for tree models (output space: probability), LinearExplainer with a training background for logistic regression (output space: log-odds). One-hot columns are summed back to the original borrower fields.

## API contract

All errors share one shape:

```json
{ "error": { "code": "model_not_trained", "message": "No trained model available...", "details": null } }
```

| Status | `code` examples | When |
|---|---|---|
| 409 | `dataset_not_loaded`, `model_not_trained`, `training_in_progress` | Call order / concurrency |
| 413 | `http_413` | Upload larger than limit |
| 415 | `http_415` | Not a `.csv` / bad content type |
| 422 | `request_validation_error`, `data_validation_error`, `insufficient_data`, `invalid_input` | Bad body, bad data, too few rows/classes |

### `GET /api/health`
```json
{ "status": "ok", "service": "credit-risk-ml", "version": "1.0.0", "timestamp": "...", "dataset_loaded": true, "model_loaded": true }
```

### `POST /api/data/upload` (multipart/form-data) → 201
Fields: `file` (CSV, required), `target_column`, `positive_labels` (comma-separated or JSON list, labels meaning *default*), `negative_labels` (labels meaning *non-default*; other labels are dropped — needed when the target has >2 values such as `Current`), `is_synthetic` (bool; inferred from filename if omitted).

```powershell
curl.exe -F "file=@data/synthetic_loans.csv" -F "target_column=loan_outcome" -F "positive_labels=Defaulted" http://127.0.0.1:8000/api/data/upload
```
Response: `{ "message", "dataset": {filename, is_synthetic, target_column, positive_labels, n_rows, ...}, "summary": <quality report> }`.

### `GET /api/data/summary?target_column=&positive_labels=&negative_labels=`
Returns `{ "dataset", "summary" }`. Summary keys: `n_rows`, `n_columns`, `columns`, `missing_values`, `duplicate_rows`, `dtype_issues`, `numeric_features`, `categorical_features`, `excluded_columns`, `numeric_summary`, `categorical_summary`, `suggested_target_columns`, `target` (`class_counts`, `default_rate`, `imbalance_ratio`, `is_imbalanced`, mapping), `leakage_warnings`, `warnings`.

### `POST /api/model/train`
Body (all optional; target defaults to the one given at upload):
```json
{
  "target_column": "loan_outcome",
  "positive_labels": ["Defaulted"],
  "negative_labels": null,
  "exclude_columns": [],
  "auto_exclude_leakage": true,
  "models": ["logistic_regression", "random_forest", "decision_tree"],
  "test_size": 0.2,
  "validation_size": 0.2,
  "random_state": 42,
  "selection_metric": "roc_auc",
  "min_default_recall": null,
  "risk_bands": [
    {"name": "Low", "max_probability": 0.2},
    {"name": "Medium", "max_probability": 0.5},
    {"name": "High", "max_probability": 1.0}
  ]
}
```
Response: `message`, `selected_model`, `selection_metric`, `decision_threshold`, `comparison` (ranked rows with validation score and test precision/recall/F1/ROC-AUC/PR-AUC, train ROC-AUC), `split`, `excluded_columns`, `trained_on_synthetic_data`, `warnings`.

### `GET /api/model/metrics`
Full metrics document (same as `models/metrics.json`): `selected_model`, `decision_threshold`, `split`, `comparison`, `models.<name>.{threshold_tuning, train, validation, test, test_at_default_threshold_0_5}`, `data` (features, exclusions, target mapping, `is_synthetic`), `notes`. Each metrics block contains `precision`, `recall`, `default_class_recall`, `f1`, `accuracy`, `balanced_accuracy`, `roc_auc`, `average_precision`, `brier_score`, `confusion_matrix` (`matrix` rows = actual `[non_default, default]`, cols = predicted), `classification_report`.

### `GET /api/model/status`
`model_available`, `is_training`, `dataset_loaded`, `model_name`, `trained_at`, `decision_threshold`, `target`, `feature_schema` (numeric fields with training min/max/median, categorical fields with known categories — use this to build input forms), `risk_bands`, `trained_on_synthetic_data`, `test_metrics`.

### `POST /api/predict`
Every model feature must be present as a key; send `null` for unknown values (they are imputed). Extra keys are ignored with a warning. Max 1000 records.
```json
{
  "records": [{
    "age": 29, "annual_income": 38000, "employment_length_years": 1.5, "employment_type": "contract",
    "home_ownership": "RENT", "loan_amount": 25000, "loan_term_months": 60, "interest_rate": 21.5,
    "loan_purpose": "small_business", "credit_score": 590, "debt_to_income": 34.0,
    "credit_utilization_pct": 85.0, "num_open_accounts": 12, "delinquencies_2y": 2
  }],
  "include_explanation": true,
  "top_k": 3
}
```
Response:
```json
{
  "model": "logistic_regression", "trained_at": "...", "decision_threshold": 0.553879,
  "risk_bands": [...], "trained_on_synthetic_data": true,
  "predictions": [{
    "index": 0, "default_probability": 0.966977, "predicted_class": "default", "predicted_label": 1,
    "risk_band": "High", "warnings": [],
    "top_factors": {
      "output_space": "log_odds",
      "increasing_risk": [{"feature": "credit_score", "value": 590.0, "shap_value": 1.35973, "effect": "increases_risk"}],
      "decreasing_risk": [{"feature": "num_open_accounts", "value": 12.0, "shap_value": -0.040929, "effect": "decreases_risk"}]
    }
  }],
  "explanation_error": null,
  "disclaimer": "Predictions are statistical estimates ..."
}
```
`predicted_class` uses the tuned `decision_threshold`; `risk_band` uses the configured probability bands. They are independent.

### `POST /api/explain`
```json
{ "records": [ { ...borrower... } ], "include_global": true, "top_k": 5, "max_summary_points": 200 }
```
Response: `model`, `explainer` (`TreeExplainer` | `LinearExplainer`), `global_explanation` (`output_space`, `base_value`, `feature_importance[]` with `mean_abs_shap`/`mean_shap`/`share_of_total`/`rank`, `summary_plot_data[]` of `{feature, points:[{feature_value, shap_value}]}` for beeswarm plots, `model_native_importance`), `local_explanations[]` (`base_value`, `model_output` = base + Σ SHAP, `predicted_default_probability`, `risk_band`, `top_risk_increasing_factors`, `top_risk_decreasing_factors`, `contributions`, `warnings`), `disclaimer`.

SHAP values describe the model's behaviour, not causes of default.

## Limitations

- **No authentication.** All endpoints are open; put this service behind the team's auth/gateway before exposing it beyond localhost.
- Single active dataset and model per process, stored on disk (no database existed to integrate with). Not designed for multiple concurrent workers writing models.
- `joblib` artifacts execute code on load; only load models produced by this service.
- Fixed, sensible hyperparameters; no hyperparameter search. The selected model is not refitted on train+validation.
- Leakage detection is name- and statistics-based; a domain review of which fields are known at approval time is still required for real data.
- No probability calibration step; treat probabilities as relative risk scores.
